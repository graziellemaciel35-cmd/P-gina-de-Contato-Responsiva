# Página de Contato Responsiva

## 📌 Sobre o Projeto

Este projeto é uma página de contato desenvolvida para websites institucionais, portfólios e sistemas web. Seu objetivo é facilitar a comunicação entre visitantes e a empresa através de um formulário simples e intuitivo.

## 🚀 Funcionalidades

- Exibição de informações de contato:
  - Endereço
  - Telefones
  - E-mails

- Formulário de contato:
  - Nome
  - E-mail
  - Mensagem

- Interface moderna e responsiva
- Fácil personalização

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela, garantindo uma boa experiência em desktops, tablets e smartphones.
